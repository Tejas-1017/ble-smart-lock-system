# BLE Smart Lock System 🔐

[![C++](https://img.shields.io/badge/C%2B%2B-Embedded-blue?logo=cplusplus)](https://isocpp.org)
[![BLE](https://img.shields.io/badge/Bluetooth_LE-RSSI-0082FC?logo=bluetooth)](https://bluetooth.com)
[![ESP32](https://img.shields.io/badge/ESP32-Security-E7352C?logo=espressif)](https://espressif.com)

A low-power proximity authentication locking system utilizing Bluetooth Low Energy (BLE) RSSI distance tracking, machine learning signal filtering, and secure embedded decision logic.

---

## 🌟 Key Features

- 📶 **RSSI Distance Classification**: Evaluates signal strength attenuation curves to accurately calculate user proximity.
- 🔒 **Fail-Safe Low Power Mode**: Implements deep-sleep standby consuming < 10µA.
- ⚡ **Instant Authentication**: Unlocks in < 1.8 ms upon verified proximity match.
